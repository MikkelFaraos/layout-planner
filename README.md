# Store Layout Planner

A single-file web app for planning and rearranging a shop floor. Open `index.html` in a browser — no install or build step.

## Features

- Drag, rotate and resize fixtures on a to-scale floor plan (grid, rulers, snapping)
- Fixture library: shelves, racks, tables, counters, walls, pillars, zones and more
- Departments with custom names and colours
- Multi-select with align and distribute tools
- Overlap / outside-the-walls check and floor-space stats per department
- Multiple saved layouts (stored in the browser), undo/redo
- Export to JSON (backup/share) and PNG; import JSON

## Shortcuts

| Key | Action |
| --- | --- |
| Drag | Move fixture / pan floor |
| Scroll | Zoom |
| Shift+Click | Multi-select |
| R / Shift+R | Rotate ±90° |
| Arrows | Nudge (Shift: 1 cm) |
| Ctrl+D | Duplicate |
| Ctrl+C / Ctrl+V | Copy / paste |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Delete | Delete |
| F | Fit store to screen |
